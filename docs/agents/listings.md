# Catalog listings

Where Tracetoon can be listed, which file in this repository backs each
listing, and how to submit it. Nothing here has been submitted yet; a person
with the right account does each submission by hand.

Every manifest below is generated by `scripts/agent-surfaces.ts` (description
from the same one-sentence pitch, version from `package.json`), and
`tests/agent-surface.test.ts` checks the fields each vendor's documentation
requires. The formats follow the vendor documentation as read on 2026-11-13.

**The `release` branch matters.** `main` carries source only: its skill has no
`build.json` or bundle, so a copy taken from `main` stops with exit code 3. The
release workflow adds the build to the `release` branch. Point every catalog
that accepts a branch or ref at `release`, and remember a manifest only reaches
`release` with the next tagged release.

## Before submitting

- [ ] Cut a release, so `release` carries the new manifests and the icon.
- [ ] Replace `plugin/assets/tracetoon.svg`, a placeholder, with real artwork
      (square, at least 48×48; Codex accepts SVG).
- [ ] Add the `gemini-cli-extension` topic to the GitHub repository.
- [ ] Check the Gemini `skills` link works from a fresh `--ref release` install
      on macOS or Linux. Git on Windows checks symbolic links out as plain
      files unless `core.symlinks` is on, so there the extension carries only
      `GEMINI.md`; the installer covers the skill.
- [ ] Ask Cursor and Kiro whether a listing can track the `release` branch.
- [ ] Codex: decide on privacy policy and terms URLs (required only for MCP
      plugins today) and a short video walkthrough.

## Validating locally

- Agent Plugins: `plugin/plugin.json` must validate against
  [plugin.schema.json](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json);
  the test checks its required keys, name pattern and that no other keys appear.
- Gemini CLI documents no `validate` command; `gemini extensions link .` from
  a `release` checkout loads the extension for a manual check.
- Cursor: `cursor/plugin-template` ships `scripts/validate-template.mjs` for its
  own layout; the test checks the same rules (kebab-case name, the manifest in
  `.cursor-plugin/`, the marketplace `source` pointing at the plugin folder,
  the logo path).
